# ADR-0005: Evidence-backed autonomy

Status: accepted; authorization confirmed by owner. Date: 2026-10-18.

Decision: [ledger](../milestones/README.md) alone owns status; FSD requirements, ADR decisions and evidence results are separate. Done requires completed dependencies and reproducible acceptance evidence. Structural validation cannot certify gameplay truth.

Use bounded outcomes and relative effort, not invented hours/tokens. Split size-8 tasks before implementation. Independently review high-risk state/continuation work; delegate disjoint investigations.

Owner permits implementation/tests/commits, pushes to fork branches and draft PRs. Merges/releases/paid resources/destructive history require explicit authorization. No recurring scheduler is introduced and existing authorization must not be repeatedly requested.

Consequences: one ledger avoids contradictory checklists; compact evidence replaces verbose transcripts. Missing game data blocks gameplay gates, not independent source work. Mocks cannot replace gameplay proof.

Reconsider storage if task volume outgrows Markdown, preserving one status authority. Revise permissions when owner directs.
